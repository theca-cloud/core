# Contributing

This repository is a read-only mirror: Theca is developed on a private forge, so issues and pull requests aren't open here.

Outside contributions need a signed Contributor License Agreement first: Theca is AGPL, and its other editions are proprietary builds of the same code. To report a bug or propose a change, write to pascal@codexa.swiss.

Commits follow [Conventional Commits](https://www.conventionalcommits.org/), scoped by crate or area (`feat(core): ...`, `fix(client): ...`): the changelog and the next version come from them.
